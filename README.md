## 📝 Project Overview

KeenKeeper is a personal relationship management web app designed to help users systematically stay connected with the important people in their lives. It enables users to track recent interactions, establish custom relationship goals, and view a simple, consolidated history of communication with friends, mentors, and family members.


## 🌟 Core Features

### 👥 Relationship Tracking
Users can manage their important connections and dynamically track how long it has been since their last interaction.

### ⚡ Quick Check-In System
Users can quickly log calls, texts, or video chats, and every interaction is automatically recorded and saved in a chronological timeline.

### 📈 Friendship Analytics
Provides interactive charts and statistics to help users visually analyze their communication habits and social activity patterns over time.

## 🚀 Local Installation & Setup Guide

Follow these steps to configure and run KeenKeeper on your local machine.

### Prerequisites

- Ensure you have **Node.js** (v18+ recommended) and **npm** installed on your system.

---

### Step 1: Clone the Repository

```bash
git clone https://github.com/Muna_Rahman/keenkeeper.git
cd keenkeeper
```

---

### Step 2: Install Dependencies

```bash
npm install
```

---

### Step 3: Run the Development Server

```bash
npm run dev
```

Open your browser and navigate to **http://localhost:5173** to view the running application.
